Environment secrets

UUID — VLESS user identifier used by every generated profile.
Trojan password — Strong, URL-safe password for Trojan authentication.
Subscription path — Secret path segment for subscription URLs. Treat it like a password.

Regenerating replaces every value in this browser. Existing deployments keep using the secrets stored in Cloudflare until you redeploy.
